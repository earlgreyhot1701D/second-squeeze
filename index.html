Prompt sent to both: The capital of France is. GPT-2 is a base model with no instruction-following, so it just continues text (here, Dart imports), and it often times out mid-answer: at 0.3 tok/s it's slow enough to trip the chat interface's own network timeout. Qwen not only answers, it runs a short reasoning pass first. A 0.6B model from 2025 out-thinking a 1.5B model from 2019.

The receipts

How this was measured, and what it isn't

  • All numbers from Lemonade's bench tool: . Same settings for every model.
  • The era comparison holds the backend fixed (CPU) on purpose. An earlier run accidentally compared GPT-2 on CPU to Qwen on GPU and showed a ~1000× gap that was mostly hardware. Controlling the backend is the difference between a real finding and a misleading one.
  • GPT-2 XL only ran on CPU. Its 2019 architecture isn't supported on the GPU backend, so it never got the acceleration the newer model did. Part of the story, not a bug.
  • Accuracy benchmarks (like LAMBADA) aren't here because Lemonade's server doesn't expose token logprobs yet, so loglikelihood evals can't run through it. That gap is written up separately and filed as a feature request.
